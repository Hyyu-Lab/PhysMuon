# 超参数

English: [hyperparameters.md](hyperparameters.md).

## 推荐设置

PhysMuon 用在一套调好的 Muon 设置之上。Muon 的学习率、权重衰减、学习率表和动量都保持不变，再加上 `physmuon` 里的一个预设：

```python
opt = PhysMuon(groups, lr=..., weight_decay=..., **language_model(total_steps))
```

| | `language_model(T)` | `interatomic_potential(T)` |
|---|---|---|
| 适用 | 语言模型 | 原子间势函数 |
| 打开的改动 | ①②③④⑤ | ①②③④ |
| 开始读出的位置 | 训练的 23% | 训练的 30.77% |
| ① 启用后的读出方式与衰减系数 | 快慢并行门控，0.85 / 0.985 | 快慢并行门控，0.90 / 0.995 |
| ② 指数 λ、截断、滑动平均衰减系数 | 0.5、[1/2, 2]、0.95 | 相同 |
| ③ 上限 `osc_wmax` | 0.6 | 0.3 |
| ④ | 开 | 开 |
| ⑤ `fresh_cap` φ | 0.25 | 关 |

两套预设在启用步前都用基线短动量，启用后切入快慢并行混合加 ③ 门控读出。论文六个原子间势函数任务中有五个直接共用 `interatomic_potential(T)` 的默认值（`beta_fast=0.90, beta_slow=0.995, w_max=0.3`）；8,000 步常规批量 SPICE2 使用 `interatomic_potential(T, beta_fast=0.85, beta_slow=0.98)`。在 deepmd-kit 里，同样的设置通过环境变量给出，见 [`integrations/deepmd/README.md`](../integrations/deepmd/README.md)。

## 新任务怎么定

论文中涉及的超参数按变动程度分为三类：

- **跨任务固定、直接用默认**：② 的三个常数（λ = 0.5、截断 [1/2, 2]、滑动平均衰减系数 0.95）、③ 的门控统计衰减 `osc_beta = 0.9`（0.80–0.95 之间都很平，不用调，见下方敏感度表），以及 ④（`bm_shadow=True`，无常数）。
- **按任务类型选择**：③ 的上限 `osc_wmax`（语言模型用 0.6，原子间势函数用 0.3）、⑤ `fresh_cap`（语言模型取 0.25，势函数关闭；其他领域建议做开/关对照）、启用步（放在训练早期损失下降最陡的那一段之后，论文语言模型用 23%、势函数用 30.77%），以及重尾梯度下的尖峰保护。
- **按任务和训练规模调整**：① 的快慢模衰减系数（`bm_beta_fast`、`bm_beta_slow`）。衰减系数为 β 的模式，平均记忆长度是 β/(1 − β) 步；两个模式混合时是 w·β_fast/(1 − β_fast) + (1 − w)·β_slow/(1 − β_slow)（可用 `physmuon.kernel_age` 和 `physmuon.beta_for_age` 换算）。

具体步骤：

1. **先调基线。** 扫 Muon 的学习率和动量，拿调好的 Muon 作对照。
2. **定 ① 的衰减系数。** 语言模型从 `0.85 / 0.985` 起步，原子间势函数从 `0.90 / 0.995` 起步（步数较少、批量较小的任务如 8,000 步常规批量 SPICE2 可取 `0.85 / 0.98`）。启用步取训练的 30% 左右（论文在势函数上取 30.77%，在 GPT-2 上取 23%）；从第一步就读长记忆，在 GPT-2 上明显变差，在势函数上会训练不稳。
3. **定 ③ 的上限 `osc_wmax`。** 语言模型从 0.6 起步，原子间势函数从 0.3 起步（`osc_beta = 0.9`，0.80–0.95 都很平，不用调）。
4. **② 用默认常数**（λ = 0.5，截断 [1/2, 2]，衰减系数 0.95）。在 MPtrj 和 SPICE2 上，改动这些常数都会使结果变差；在 GPT-2 上，λ 和衰减系数也以这组取值最好，截断放宽到 [1/3, 3] 没有差别。② 每一步至少需要两份独立的梯度估计：微批，或不同 GPU 上的梯度。
5. **④ 直接打开。** 它没有常数。
6. **⑤ 用于语言模型**（φ = 0.25）；原子间势函数任务保持关闭（换到其他领域时可对照 φ = 0.25 与 0）。
7. **梯度重尾时。** 在梯度范数偶尔极大的大型晶体数据集上，打开尖峰保护：`PhysMuon` 里设 `spike_guard=10`；deepmd-kit 的 DPA4 钩子里设 `BM_GATE_K=10`，并建议同时设 `ISO_SPIKE_SKIP=1`。

比较不同配置时，建议使用多组配对的 seed 与相同的数据顺序。

## 各常数在 GPT-2 上的敏感程度

每个取值 4 个配对的 seed，推荐值用粗体标出。完整的表见 [`experiments/language_model/ablations.md`](../experiments/language_model/ablations.md)。

| 常数 | 试过的取值 | 对验证损失的影响 |
|---|---|---|
| 启用步 `bm_start` | 0、500、**750**、1,000 | 取 0 时高 0.0065；500 持平；1,000 约差 0.0005 |
| 慢模 `bm_beta_slow` | 0.98、**0.985**、0.99 | 相对读出比例固定的 ①：−0.0033、**−0.0039**、−0.0012 |
| 快模 `bm_beta_fast` | 0.80、**0.85**、0.90 | +0.00104、**0**、+0.00060 |
| 上限 `osc_wmax` | 0.5、**0.6**、0.7 | 0.5 和 0.7 约差 0.0004 |
| 新鲜份额 `fresh_cap` | 0.15、**0.25**、0.35、0.45 | 比关闭 ⑤ 分别低 0.00037、**0.00052**、0.00045、0.00016 |
| ② 的指数 `iso_lam` | 0.25、**0.5**、1.0 | 1.0 约差 0.002；0.25 保留约 80% 的收益 |
| ② 的截断 `iso_clamp` | **2**、3 | 没有差别 |
| 门控的滑动平均衰减系数 `osc_beta` | 0.80、**0.9**、0.95 | +0.00013、**0**、+0.00011 |
| ② 的滑动平均衰减系数 `iso_beta` | 0.90、**0.95** | 取 0.90 时 +0.00031 |
