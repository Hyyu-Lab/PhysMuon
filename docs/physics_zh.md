# 五项改动的物理来历（按 arXiv:2608.22994 的图景）

## 起点：论文里的 Muon

论文把一个权重矩阵看成响应介质，输入信号经过它产生输出。训练损失是失配势 Φ，它对权重的负梯度 X = −∂Φ/∂W 是推动介质重排的共轭驱动力。

空间上，介质每一步的重排受输出限幅约束：对任何输入方向，输出的变化都不超过同一个上限。要在这个约束下让失配势下降得最快，每个受驱动的集体模式都应以同一速度移动；对应的更新方向是驱动力的半正交化，也就是 Muon 的更新。

时间上，介质响应的是内部应力记忆 M，它按 τ·dM/dt = X − M 松弛；这个方程离散化后就是动量 EMA。

这个模型里有两处取了最简单的形式：所有通道共用一个各向同性的输出限幅；内部应力只有一个松弛时间。五项改动都是把这两处换成更接近真实介质的形式。② 改的是空间上的限幅，其余四项改的是时间上的记忆。

## ① 快、慢两个松弛模式

**缺了什么。** 复杂介质内部有多种重排方式，每种方式有自己的松弛时间，这些松弛时间合起来构成一个正的松弛谱。Muon 只保留了其中一个模式，于是同一个 τ 既决定响应快慢，又决定记忆深浅，两者无法兼顾。

**怎么改。** 从松弛谱中只保留两个代表模式，一快一慢，按正权重做凸组合：M = w·M_f + (1−w)·M_s，τ_f < τ_s。权重为正、和为 1，对应“每个内部模式受力都与外力同号”的介质类别。

**结果。** 调好的 Muon 基线在 3250 步内未达标；用论文常数（快 0.85、慢 0.98、w = 0.4385，平均记忆长度 30 步，第 1000 步启用）加入 ① 后，在第 3205 步达标；固定 w = 1/6 时为第 3200 步。

## ② 按涨落校准的输出预算

**缺了什么。** Muon 的输出限幅对所有通道一视同仁。在随机梯度下，不同输出通道、不同输入通道上的驱动力涨落相差很大；在涨落大的通道上，同样幅度的一步里噪声占的比例更高。

**怎么改。** 把限幅换成加权限幅：输出变化按 g 加权，输入幅度按 h 计量。在加权坐标里重做论文中的推导，最优运动仍然是一个极分解，只是先变换到加权坐标，做完再变换回来：V = g^(−1/2)·polar(g^(−1/2)·X·h^(−1/2))·h^(−1/2)。度量由驱动力的采样涨落确定。每个样本的力是输出误差与输入激活的外积；假设两者的二阶矩可以分开，涨落就分成行（输出通道）和列（输入通道）两个因子。我们让阻尼与涨落方差的 λ 次方成正比，取实测最优的 λ = ½（λ = 1 时验证损失高约 0.002，λ = ¼ 时只保留约八成收益），并把度量限制在 [½, 2] 内。涨落方差直接用同一步里各微批梯度之间的差来估计，不需要额外的前向和反向计算。

**结果。** 单独使用时达标步数为 3190；叠加在 ① 上为 3160，两者近似可加（交互项 +0.0003）。在 302M 模型上收益更大，3250 步时的损失比 Muon 低 0.013。

## ③ 门控读出

**缺了什么。** ① 里快慢两个模式的读出比例 w 是固定常数。但介质受的力在训练中会变：前期学习率大，回弹强；冷却后回弹消失。固定的 w 跟不上这个变化。

**怎么改。** 把每步的力分成三部分：持续漂移 s（地形长期推动的方向），回复力 r（介质对自己上一步过冲的弹性回弹，方向每步翻转，周期约 2 步），以及批噪声。EMA 对周期为 2 的分量的漏过率是 (1−β)/(1+β)，快模为 ρ_f = 0.081，慢模只有 0.0075。因此快模里存的是“漂移加上 0.081 倍的回弹”。快模值不值得读，取决于其中回弹残余与漂移的比值 ρ_f·o/d：o 衡量力与快模反向的程度（回弹强度），d 衡量慢模相对当前力的大小（漂移强度）。快模的权重就取它的“漂移纯度”：w = w_max·(1 − ρ_f·o/d)₊。

切换时 o/d 约为 13，ρ_f·o/d 接近 1，w 接近 0，主要读慢模；冷却后回弹随学习率下降而消失（−cos(g, M_f) 从 0.47 降到 0.07），w 升到 0.5–0.6。这条规则不含步数和学习率，每个矩阵每一步自己测量。

**结果。** 只开 ① 时加门控，达标步数为 3150（第 1000 步启用；固定 w 取最优的 1/6 时为 3200）；在 ①② 上加门控为 3100。

## ④ 从第 0 步起跟踪

**缺了什么。** 原来的做法是在启用步把两个模式都从 Muon 动量复制出来。内部松弛模式是介质本身的一部分，不会在启用时才出现。慢模的记忆时间约 66 步，Muon 动量只有约 19 步的历史，直接复制相当于给慢模一个与它自身历史不符的初值。这份冻结的快照要几十步才衰减掉，在此期间更新沿冻结方向直线推进，损失先升高（第 875 步比从第 0 步起跟踪的版本高约 0.02）再回落。

**怎么改。** 从第 0 步起就让两个模式和门控统计跟踪原始梯度，启用步只把读出从单模动量切换到两个模式。

**结果。** 启用时的冲击消失，不含 ② 的叠加从 3140 提前到 3130，含 ② 的叠加从 3100 提前到 3095，8 个 seed 全部变好。

## ⑤ 新鲜份额上限

**缺了什么。** 进入极分解的是 Nesterov 混合 u = (1−μ)·g + μ·M。门控读得深时，M 的范数被平均得更小，直接支路 (1−μ)·g 的份额（按模长计，(1−μ)|g| / ((1−μ)|g| + μ|M|)）从固定读出比例时的约 33% 升到约六成。注意 M 在混合之前已经吸收了本步梯度：本步梯度在 u 中的总系数是 (1−μ) + μa，a = w(1−β_f) + (1−w)(1−β_s)；这里的份额只计直接支路。实测表明，在刚性的主子空间里，起伏几乎全部来自优化器自己过冲后的回弹，批噪声可以忽略。直接支路的份额一升高，更多的回弹就被送进极分解。

**怎么改。** 让直接支路的份额不超过 φ：需要时调大 μ，只收紧、不放宽，即 μ_t = max(μ, 1/(1 + φ/(1−φ)·|M|/|g|))，φ = 0.25。两种只在部分子空间里收紧的版本都更差（只去掉软方向上的当前梯度会变差，说明那部分是有用信息），所以采用全局形式。

**结果。** 不含 ② 的叠加从 3130 提前到 3120，含 ② 的叠加从 3095 提前到 3085，两组都是 8 个 seed 全部变好。

## 汇总

| 改动 | 改变了介质的哪一部分 | 依次叠加后的达标步数（124M，8 seed） |
|---|---|---|
| Muon（基线） | 各向同性限幅 + 单一松弛时间 | 3250 步内未达标 |
| ① 快、慢两个松弛模式 | 松弛谱取一快一慢两个模式 | 3205 |
| ② 按涨落校准的输出预算 | 输出限幅按涨落加权 | 3160 |
| ③ 门控读出 | 快慢读出比例由回弹与漂移的实测比值决定 | 3100 |
| ④ 从第 0 步起跟踪 | 记忆模式从第 0 步就存在，启用时只切换读出 | 3095 |
| ⑤ 新鲜份额上限 | Nesterov 直接支路在更新输入中的份额不超过 φ | 3085 |
